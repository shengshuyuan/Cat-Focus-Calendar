# 像素时钟第一版

本分支实现 FoloToy AI Passport 的第一段视觉与交互：按照屏幕原生 240×320 竖屏比例，制作纸张色像素风万年历、中国撕页日历和猫咪番茄钟页面。

## 已包含

- 万年历为开机页面，当前页同时显示选中公历日期、农历和节气；`UP`、`DOWN` 切换月份，`OK` 直接进入番茄钟。
- 在万年历长按 `UP` 进入中国撕页日历。该页与万年历共享选中日期，显示星期、农历、节气、干支和个人专注建议；`UP`、`DOWN` 分别查看前一天、后一天，`OK` 返回万年历。「宜忌」是个人日程提示，不是权威传统黄历。
- 万年历覆盖 1900—2100 年的离线农历月份和二十四节气，农历信息不依赖 Wi-Fi。
- 番茄钟默认 25 分钟。待开始时 `UP` 在 15、25、45 分钟之间轮换；`DOWN` 回到万年历，不会暂停正在进行的计时；`OK` 开始、暂停、继续或启动提示的休息阶段。
- 番茄钟页面长按 `OK` 返回万年历。
- 在万年历主页面长按 `DOWN` 进入 Wi-Fi 配网页；配网成功后用 NTP 校准设备时间，农历查询本身不依赖网络。
- 番茄钟状态和完成轮数使用参考实现的 NVS 存储，重启后运行中的任务会安全恢复为暂停。
- 使用一个精简 LVGL 中文字体，覆盖本页面所需字形。字体源是开发机已安装的 LXGW WenKai Medium，仓库只跟踪生成后的 C 字形表。
- 重新生成时必须加 `--no-compress`（仓库未开 `CONFIG_LV_USE_FONT_COMPRESSED`），导出符号保持 `folotoy_font`；漏字或压缩未解压都会让中文整段空白。增删文案后要同步扩展 `--symbols` 并真机验收配网页、节气与番茄文案。
- 猫、绿植、书、山景和枝叶等固定插画使用位于 Flash 的 RGB565 资源，避免用数百个 LVGL 对象拼画；资源说明见[像素时钟插画资源](../assets/images/pixel-clock/README.zh_CN.md)。
- 专注计时进行中，番茄钟下半部从睡着的三花猫切换为同构图的清醒站立三花猫；待开始、暂停和休息继续显示休息场景。
- 底栏改为三枚深色按钮，使用与页面状态对应的像素图标，不再绘制稿外的四格进度点。
- 十分钟没有 `CLICK` 或 `LONG` 按键事件后，固件只把显示背光降为 0；当前页面和番茄钟状态仍保留。首次符合条件的按键只恢复背光、不执行跳页，下一次按键才操作 UI。这不是显示控制器休眠或深度睡眠。

## 农历与节气数据

数据由 `lunar-python` v1.4.8（MIT）在开发机生成成 C 静态表，设备端只做二分查表，不携带 Python 运行时，也不请求第三方接口。示例校验：2026-09-09 是农历七月廿八，2026 年白露是 9 月 7 日；设计稿中的“八月初九”作为视觉示例，不作为天文数据。

## Wi-Fi 怎么接入

固件没有写入你的家庭 Wi-Fi 名称或密码。首次使用按下面操作：

1. 在万年历主页面长按 `DOWN`，进入“Wi-Fi 配网”。
2. 按 `OK` 开启 BLE 配网，屏幕会显示唯一设备名，例如 `FoloToy-12AB34`。
3. 手机上安装 Espressif 的 **ESP BLE Provisioning** 应用，搜索这个设备名并连接。协议说明见 [ESP-IDF Wi-Fi Provisioning](https://docs.espressif.com/projects/esp-idf/en/v5.5.3/esp32/api-reference/provisioning/wifi_provisioning.html)。
4. 在手机应用里选择家中的 2.4 GHz Wi-Fi，输入密码并提交。凭据通过配网流程发送给设备，并保存到 ESP-IDF 的 Wi-Fi NVS；固件源码和屏幕都不会显示或预置家庭密码。
5. 屏幕变为“已连接”后，设备会请求 `ntp.aliyun.com` 和 `pool.ntp.org` 校时。长按 `OK` 返回万年历。

当前开发版使用 BLE 配网安全等级 0，目的是先验证真机流程；正式发布前应切换到每台设备独立 PoP 的安全等级 1，并在机身或二维码中提供 PoP。

## 真机测试记录

2026-09-10 的上一份固件快照使用 ESP-IDF v5.5.3 构建，并通过 `/dev/cu.usbmodem1101` 使用 `idf.py flash` 增量刷入 ESP32-C3。刷写只覆盖 bootloader、分区表和 factory app 范围，没有触碰 `0x356000` 的 `cardid` 保护分区。新增的十分钟闲置背光功能尚未在当前环境重新构建，因为所需 ESP-IDF Python 虚拟环境缺失。最终仍需在设备上人工观察三张主页面，并按下每个按键完成万年历翻月、中国日历前后一天、番茄钟开始/暂停、配网入口、闲置熄屏唤醒和保护分区验收。
